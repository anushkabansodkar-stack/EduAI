# EduAI Frontend Only

This package contains the React + Vite frontend (`src/` and `public/`) and the configuration needed to run it. Backend folders and server files are not included.

## Run
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`

Note: API-powered features may need the separate backend server to be running.
